# HTTP Status Code

An educational project exploring **HTTP status codes**, their meanings, and their roles in web communication. This repository contains 14 HTML versions, from Version 0 through Version 13, documenting the project's iterations and development.

## Overview

HTTP status codes are three-digit numbers returned by web servers to indicate the outcome of an HTTP request. They help developers understand whether a request succeeded, requires further action, or encountered an error.

This project provides a foundation for learning about HTTP status codes and their importance in web development, troubleshooting, and API communication.

## HTTP Status Code Categories

HTTP status codes are grouped into five main categories:

| Code Range | Category | Description |
|---|---|---|
| 100–199 | Informational | The request has been received and processing continues. |
| 200–299 | Success | The request was successfully received, understood, and processed. |
| 300–399 | Redirection | Further action is needed to complete the request. |
| 400–499 | Client Error | An error occurred with the request from the client. |
| 500–599 | Server Error | The server failed to fulfill a valid request. |

## Why HTTP Status Codes Matter

Understanding HTTP status codes helps developers:

- Troubleshoot website and API errors.
- Understand communication between clients and servers.
- Handle successful requests and redirects appropriately.
- Diagnose client-side and server-side problems.
- Build more reliable web applications.
